Assemblage d’un robot conversationnel

Un robot conversationnel est un programme informatique conçu pour simuler une discussion avec un utilisateur.

Dans cette activité, tu vas assembler et personnaliser un robot conversationnel.

L'activité est divisée en 5 parties :

  1. Mise en place
  2. Création des médias
  3. HTML
  4. CSS
  5. JavaScript

A. La mise en place

Préparer les outils et le dossier du projet.

  1. Dans ton explorateur de fichiers, ouvre le dossier Techno Branche Etu et observe son contenu.
    • Le dossier Exercice contient les fichiers index.html, README.md et les sous-dossiers css, images, js et sounds.
    • Le dossier Matériel contient le visuel des six thématiques disponibles.
  2. Ouvre le prototype de départ: dans le dossier Exercice, double-clique sur le fichier index.html pour l'ouvrir dans un navigateur.
  3. Écris un message au robot conversationnel dans le champ prévu à cet effet et celui-ci te répondra avec une phrase aléatoire.

B. Création des médias

Créer l’identité visuelle de ton robot conversationnel avec Adobe Illustrator, un logiciel de création graphique vectorielle.

Toutes les illustrations que tu vas observer dans les prochaines étapes ont été conçues par une personne diplômée du programme TIM. Leur conception fait partie des compétences développées dans le programme.

Étape 1 - Choisir une thématique

Le dossier Matériel contient un fichier Illustrator pour chacune des six thématiques proposées.

Les noms de fichier se terminant par « .ai » indiquent qu'ils ont été créés avec Adobe Illustrator.

Tu peux choisir parmi les thématiques suivantes 

La mode
La musique
La cuisine
Les gardiens de la planète
Le sport
Les jeux vidéo
  1. Double-clique sur le fichier Illustrator de la thématique qui t'intéresse pour ouvrir la bibliothèque d’éléments graphiques permettant de créer l’avatar de ton robot conversationnel.
  2. Pour te déplacer dans le document Illustrator:
    • sélectionne l'outil Main dans la barre d'outils
      ou
    • maintiens la barre d’espace et clique-glisse.
Étape 2 - Créer ton avatar

Nous allons créer un avatar qui représentera ton robot conversationnel.

  1. Explore les différentes pièces disponibles dans la section 1. Bibliothèque d’éléments pour avatar  yeux, bouches, chapeaux, accessoires, etc.
  2. Déplace les pièces de ton choix dans la zone 2. Préparation de l’avatar pour assembler ton avatar.
  3. Superpose plusieurs éléments pour créer des effets originaux.
  4. Expérimente jusqu’à obtenir la combinaison qui te plaît.
Étape 3 - Exporter et organiser ton avatar

Exporter ton avatar

Une fois l’avatar construit, exporte-le 

  1. Va dans le menu Fichier > Exporter > Exporter pour les écrans....
  2. Dans la fenêtre qui apparaît, configure les paramètres suivants:
    • Dans Plans de travail, coche uniquement le 2e item. Il s’agit du plan de travail qui contient l’avatar que tu viens d’assembler.
    • Décoche Créer des sous-dossiers.
    • Sélectionne Échelle 2x et PNG
  3. Clique sur Exporter le plan de travail.

Organiser ton avatar

L’avatar a été exporté dans le dossier Matériel avec le nom par défaut ExporterAvatar@2x.png.

  1. Dans l’explorateur de fichiers, navigue jusqu’au dossier Matériel et trouve ExporterAvatar@2x.png.
  2. À l'aide du trackpad de ton poste, fais un clic secondaire pour afficher des actions supplémentaires.
  3. Renomme ce fichier mon-avatar.png (clic secondaire > Renommer).
  4. Copie ce fichier (clic secondaire > Copier).
  5. Navigue ensuite jusqu'au dossier Exercice/images et colles-y ce fichier (clic secondaire > Coller).

Pourquoi exporter mon avatar en format PNG ?

Le PNG est un format d’image optimisé pour le Web  il est léger, compatible avec les navigateurs et capable de conserver la transparence de l’arrière-plan. C’est idéal pour intégrer ton avatar dans une interface Web.

C. HTML

Structurer l’information avec l'éditeur de code VSCodium (VSC).

Le langage HTML permet de structurer l'information dans une page et de donner du sens à son contenu.

Étape 4 - Ouvrir un projet dans VSC

Dans cette section, tu vas intégrer ton avatar dans le robot conversationnel.

  1. Ouvre VSC.
  2. Va dans Fichier > Ouvrir le dossier… (File > Open Folder...).
  3. Sélectionne le dossier Exercice.
  4. Clique sur Ouvrir (Open).

Ce que tu devrais voir dans ton éditeur de code

Pourquoi utiliser un IDE (Integrated Development Environment) comme VSC plutôt que le bon vieux Notepad ?

L’architecture d’un site Web peut être complexe. Un IDE permet de naviguer plus rapidement entre les fichiers du projet, d’utiliser des extensions et de profiter d’outils qui facilitent la programmation.

Étape 5 - Personnaliser le nom et le sous-titre

Retourne rapidement dans ton navigateur pour observer l’en-tête du robot conversationnel : nous allons y personnaliser l’avatar, le titre et le sous-titre.

  1. Dans VSC, ouvre le fichier index.html à partir de l’explorateur. C’est dans ce fichier que se trouvent les éléments HTML qui s’affichent sur le site Web : texte, structure, images, etc.
  2. Dans le code HTML, remarque les différentes balises utilisées pour structurer l’information : <h1>, <h2>, <img>, etc. Chaque balise a une signification différente.

Dans les prochaines étapes, tu devras enregistrer régulièrement ton travail dans VSC avec Ctrl+S, puis cliquer sur le bouton Rafraîchir () dans ton navigateur pour voir le résultat.

Personnaliser le nom et le sous-titre

  1. Repère les balises <h1> et <h2> situées dans l’en-tête. Elles contiennent respectivement le nom et le sous-titre actuels du robot conversationnel.
  2. Remplace le texte entre <h1> et </h1> par le nom que tu as choisi pour ton robot conversationnel. Sois créatif.
  3. Remplace le texte entre <h2> et </h2> par ton propre sous-titre.
  4. Enregistre tes modifications, puis rafraîchis () la page dans ton navigateur.
Résultat attendu
Le nouveau nom et le nouveau sous-titre de ton robot conversationnel devraient apparaître dans l’en-tête.

Le langage HTML

Le HTML ne possède aucune capacité de programmation. Son rôle est de structurer l’information  titres, paragraphes, images, boutons, etc.

Cette structure est ensuite stylisée grâce au CSS, puis animée et rendue interactive grâce au JavaScript. Ces trois technologies sont indispensables pour créer un site moderne.

Étape 6 - Intégrer ton avatar

Repère la balise <img> qui affiche l’avatar. Elle contient un attribut src (source) qui indique le chemin du fichier image à afficher.

  1. Modifie le chemin pour qu’il pointe vers l’avatar que tu as créé précédemment  mon-avatar.png.
  2. Enregistre la modification et rafraîchis () la page dans ton navigateur.
Résultat attendu
Ton avatar devrait maintenant apparaître dans le robot conversationnel.
Étape 7 - Améliorer l’accessibilité

As-tu remarqué le deuxième attribut de la balise <img>  alt ? Il s’agit d’un texte alternatif qui décrit l’image pour les personnes qui utilisent un lecteur d’écran, ou lorsque l’image ne peut pas s’afficher.

  1. Repère l’attribut alt dans la balise <img> de ton avatar.
  2. Modifie le texte pour qu’il décrive fidèlement ton image. Par exemple  Avatar d’un astronaute avec des lunettes de soleil.
  3. Enregistre ta modification, puis rafraîchis () la page dans ton navigateur.

En quoi le texte alternatif est-il utile si je ne le vois jamais ?

Il est indispensable pour rendre Internet accessible à tous. Une personne ayant un trouble de la vue peut utiliser un lecteur d’écran pour naviguer sur le Web. Quand le lecteur rencontre une image, il se fie au texte alternatif pour la décrire à voix haute. Ainsi, la personne sait ce que représente l’image.

D. CSS

Styliser la page.

Le langage CSS (Cascading Style Sheets) permet de modifier le visuel d'une page HTML.

Étape 8 - Ajuster les couleurs

Pour les prochaines étapes, consulte la section 3. Interface du fichier Illustrator de ta thématique. Cette section contient les informations visuelles et interactives de l’interface :

  • les couleurs du bouton pour soumettre le message;
  • les couleurs générales et celles des bulles de conversation;
  • la typographie du titre et du sous-titre;
  • un aperçu visuel du résultat attendu;
  • le son à émettre lors de la réception d’une réponse.

Chaque couleur est identifiée par un code hexadécimal qui débute par #. Par exemple, #000000 correspond au noir et #FFFFFF au blanc.

Ajuster les couleurs

  1. Dans VSC, ouvre le fichier css/style.css à partir de l’explorateur.
  2. Repère le conteneur :root. Des règles de style sont déjà prévues pour accueillir les couleurs de ta thématique.
  3. En te fiant au fichier Illustrator, copie-colle les codes hexadécimaux aux bons endroits.
  4. Enregistre la modification et rafraîchis () la page dans ton navigateur.
Résultat attendu
Les couleurs de ton robot conversationnel devraient maintenant ressembler à l’exemple présenté dans Illustrator.
Note importante
Chaque code hexadécimal doit commencer par # (exemple  #FF5733) et chaque ligne de code doit se terminer par un point-virgule ;.
Étape 9 - Modifier la police de caractères

Le robot conversationnel utilise actuellement la police de caractères Arial. Nous allons la remplacer par la police prévue pour ta thématique: il s’agit de Fredoka.

Identifier la police

  1. Consulte la section 3. Interface du fichier Illustrator.
  2. Repère la police indiquée pour le titre et le sous-titre.

Obtenir le code de la police

  1. Ouvre Google Fonts dans ton navigateur et recherche la police indiquée dans ton kit (Fredoka).
  2. Sélectionne la police.
  3. Clique sur Get font, puis sur Get embed code.
  4. Dans l’onglet Web, sélectionne @import.

Intégrer la police

  1. Copie seulement la ligne @import et colle-la tout en haut du fichier style.css dans VSC.
  2. Copie seulement la ligne font-family et remplace la ligne correspondante dans le fichier CSS.
  3. Enregistre la modification et rafraîchis () le robot conversationnel dans ton navigateur.
Résultat attendu
La police du titre et du sous-titre devrait maintenant correspondre à celle présentée dans Illustrator.
Étape 10 - Modifier le mini-avatar des bulles

La bulle de discussion est présentement accompagnée d’un mini-avatar par défaut.

La section 3. Interface du kit Illustrator prévoit une icône du robot conversationnel selon ta thématique.

E. JavaScript

Ajouter l’interactivité.

Le JavaScript est un langage de programmation qui rend une page Web interactive.

Étape 11 - Ajouter un effet sonore

Ici, tout est déjà programmé  il suffit d’activer le son.

  1. Ouvre le fichier js/script.js dans VSC.
  2. Repère la ligne qui est actuellement mise en commentaire, précédée de //.
  3. Retire les deux barres obliques // au début de la ligne pour activer le code.
  4. Modifie le nom du fichier pour qu’il pointe vers le son correspondant à ta thématique, déjà prêt dans le dossier /sounds/.
  5. Enregistre ta modification, puis rafraîchis () la page dans ton navigateur.

Résultat attendu
Un son devrait maintenant se faire entendre chaque fois que le robot conversationnel commence à répondre à ton message.

Assure-toi que les haut-parleurs de ton ordinateur sont activés pour entendre le son.

Étape 12 - Modifier les réponses automatiques

Chaque fois que tu écris un message, le robot conversationnel choisit une réponse au hasard dans une liste enregistrée dans le fichier script.js.

  1. Repère la liste qui commence par const phrases = [.
  2. Remplace les phrases entre guillemets par tes propres réponses.
  3. Tu peux modifier toutes les phrases ou seulement celles que tu souhaites personnaliser.
    Attention — Conserve les guillemets " " et les virgules entre les phrases.
  4. Enregistre ta modification, puis rafraîchis () la page dans ton navigateur.
Résultat attendu
Le robot conversationnel devrait maintenant répondre avec les phrases que tu as écrites.
